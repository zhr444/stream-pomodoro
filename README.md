# Таймер Pomodoro (Pomodoro Timer)

Продвинутый и глубоко настраиваемый таймер Помодоро для контроля времени работы и отдыха. Проект имеет стильный дизайн с автоматической сменой цветовых схем в зависимости от текущего режима. Разрабатывался в том числе для удобного захвата экрана (через OBS) во время стримов по Minecraft и Euro Truck Simulator 2.

## Особенности
* **Режимы работы:** Три классических режима (Работа, Короткий отдых, Длинный перерыв) с автоматическим переключением после 4 циклов.
* **Точный расчет времени:** Защита от "засыпания" фоновых вкладок браузера за счет постоянной сверки с системным временем (`Date.now()`).
* **Глубокая кастомизация времени:** Возможность задать собственное время (в часах и минутах) для каждого режима с защитой от некорректного ввода (лимит до 24 часов).
* **Мультиязычность:** Встроенная поддержка 9 языков (включая русский, английский, китайский, украинский, белорусский и казахский) с динамической локализацией интерфейса и формата даты.
* **Визуализация:** Индикатор пройденных рабочих циклов (помидоров) и плавная полоса прогресса.
* **Звук без файлов:** Звуковые уведомления генерируются программно через `Web Audio API` — никаких проблем с подгрузкой внешних MP3-файлов.
* **Настройки отображения:** Включение/отключение миллисекунд и живые системные часы, привязанные к локали.

## Технологии
* **HTML5**
* **CSS3** (CSS-переменные, Flexbox, Transitions)
* **JavaScript** (Vanilla JS, Web Audio API)

## Запуск проекта
Проект работает полностью на стороне клиента.
1. Склонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
